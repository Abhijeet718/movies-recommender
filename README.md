# 🎬 Movie Recommendation System

A content-based Movie Recommendation System built using FastAPI, Scikit-learn, and TMDB API.

## 🚀 Live Demo

https://movies-recommender-6ylk.onrender.com

## 📌 Features

* Search movies
* Get movie recommendations
* Autocomplete suggestions
* Movie details page
* Posters and ratings from TMDB
* Responsive UI

## 🛠️ Tech Stack

* Python
* FastAPI
* Scikit-learn
* Pandas
* HTML/CSS
* TMDB API
* Render

## 📂 Project Structure

movies-Reccomender/
├── main.py
├── models/
├── static/
├── templates/
├── requirements.txt
└── README.md

## ⚙️ Installation

```bash
git clone https://github.com/Abhijeet718/movies-recommender.git
cd movies-recommender
pip install -r requirements.txt
uvicorn main:app --reload
```
